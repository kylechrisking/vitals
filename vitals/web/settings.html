Sites

    
A site is a group of hosts and services that share a network, power or a job, like everything on one UPS,
      or the media stack. It counts as down only when enough of its members are down at the same time, so one
      machine rebooting isn't a site outage.

    

    

    

  


  

    
Hosts

    
Machines running the Vitals agent. Limits here apply to every host unless a host has its own.

    

    

    

  


  

    
Checks

    
Everything Vitals watches. A muted check is still checked and still shown, it just never sends an alert.

Quiet hours and reminders

    
During quiet hours alerts are held and sent as one summary when they end. A notifier can be set to ignore quiet hours.

    

      
      
    

    
Maintenance windows

    
Repeating times when things are expected to go down, like nightly backups or a reboot window. Checks still
      run and show, but nothing alerts and it doesn't count against uptime.

    

    

  


  

    
Activity

    
Every alert Vitals raised, newest first, and where it went.
